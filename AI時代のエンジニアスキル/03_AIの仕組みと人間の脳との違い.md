# 03. AIの仕組みと人間の脳との違い

[← 目次に戻る](README.md)

Claude や ChatGPT のような**大規模言語モデル（LLM）**の仕組み。

## 1. 一言でいうと

> **「これまでの文章から、次に来る単語（トークン）を予測する」処理を、1つずつ繰り返している。**

```
入力：「日本の首都は」
  → 予測：「東京」(92%)「京都」(3%)「、」(2%)…
  → 「東京」を選ぶ
入力：「日本の首都は東京」
  → 予測：「です」(85%)「。」(10%)…
  → 「です」を選ぶ
  …これを繰り返して文章ができあがる
```

次の単語を正確に当てるには、文法、事実、論理、文脈、意図の理解が必要。膨大なデータで学習するうちに、結果として**推論やコーディングのような能力が身についた**と考えられている。

---

## 2. 内部の処理の流れ

### ① トークン化：文章を細かく区切る
```
「AIはコードを書く」 → [AI] [は] [コード] [を] [書く]
```
日本語だと1文字〜数文字で1トークン程度。

### ② 埋め込み（ベクトル化）：意味を数値にする
各トークンを数千次元の数値の列（ベクトル）に変換する。意味の近い言葉はベクトル空間で近くに配置される。
```
「犬」 → [0.21, -0.54, 0.88, …]
「猫」 → [0.19, -0.49, 0.85, …]  ← 犬と近い
「車」 → [-0.73, 0.12, -0.31, …] ← 犬とは遠い
```
例：「王様 − 男 ＋ 女 ≒ 女王」のような計算が成り立つ。

### ③ Transformer：文脈を理解する
2017年に発表された構造。中心は **Attention（注意機構）**。
各単語が「文中のどの単語に注目すべきか」を計算する。

```
「銀行の口座を開いた。そこで通帳を受け取った。」
「そこ」を処理するとき → 「銀行」に強く注目
```

これを何十層も重ねることで、低い層では文法、中間では意味、高い層では論理や意図…と、だんだん抽象的な理解が組み上がると考えられている。

### ④ 出力：確率から選ぶ
すべてのトークン候補について「次に来る確率」を計算し、1つを選ぶ。
- 常に一番確率の高いものを選ぶ → 安定するが単調
- ある程度ランダムに選ぶ（**Temperature** で調整）→ 多様だがブレる

→ **同じ質問でも毎回少し違う答えが返ってくる理由。**

## 3. 学習の仕組み

### ① 事前学習（Pre-training）
- インターネットの文章、書籍、コードなど**数兆トークン**を読み込む
- 「次の単語を当てる」問題を解き、間違えるたびに**パラメータ（数千億〜数兆個の数値）**を少しずつ調整
- 言語、知識、推論能力の土台ができる

### ② 事後学習（Post-training）
- 「文章の続きを書く機械」から「質問に答えるアシスタント」に調整する
- 人間やAIが良い回答・悪い回答を評価し、良い方向へ寄せる（RLHF などの強化学習）
- 安全性、正確さ、有用性もここで調整
- コードを実行してテストが通るかで報酬を与えるなど、**検証できるタスクでの強化学習**がコーディング能力の向上に効いている

### 重要なポイント
- 知識はパラメータの中に**分散して**記憶されている。データベースのように取り出せるわけではない
- 学習が終わるとパラメータは固定される → **会話しても学習はしない**（会話内の内容は一時的に覚えているだけ）

## 4. 人間の脳との違い

| 観点 | 人間の脳 | LLM |
|---|---|---|
| **基本単位** | ニューロン 約860億個、シナプス 約100兆個 | パラメータ 数千億〜数兆個 |
| **信号** | 電気と化学物質のパルス | 数値の行列計算 |
| **学習方法** | 少ない経験から学べる | 膨大なデータが必要 |
| **学習のタイミング** | 生きている間ずっと学び続ける | 学習期間が終わると固定 |
| **記憶** | 短期・長期・エピソード記憶など多様 | パラメータ（長期）＋コンテキストウィンドウ（作業記憶） |
| **入力** | 五感と身体で世界と直接やりとり | 主にテキスト（最近は画像・音声も） |
| **処理の流れ** | 双方向、常に並行して動いている | 基本的に入力から出力への一方向（1トークンずつ） |
| **消費電力** | 約20W | データセンターで数MW規模 |
| **目的・動機** | 生存、感情、欲求 | 学習で最適化された目標のみ |
| **意識・主観** | ある | あるかどうかは未解明 |

### 似ている点
- どちらも「たくさんの単純な要素のつながり」から複雑な能力が生まれている
- 人工ニューラルネットワークは、脳の神経細胞をヒントに作られた
- 脳も「次に何が起こるか予測している」という理論（予測符号化）がある

### 決定的な違い
- **人間は世界を体験して理解する**：「熱い」は実際に触って知る
- **LLMは言葉と言葉の関係から理解する**：「熱い」は文章での使われ方から学ぶ

→ LLMは言葉の上では賢い一方で、**物理的な感覚や常識を取り違える**ことがある。

## 5. 仕組みから分かる「AIの癖」と対処法

| 仕組み | 起きること | 対処法 |
|---|---|---|
| 「もっともらしい次の単語」を予測 | **ハルシネーション**（存在しないAPIをそれらしく書く） | ドキュメントを渡す、実行して検証させる |
| 知識は学習時点で固定 | 最新ライブラリの仕様を知らない | バージョンを明示、公式ドキュメントを渡す |
| コンテキストウィンドウに限りがある | 長い会話で最初の指示を忘れる | タスクを区切る、CLAUDE.md に書く |
| Attention で文脈を読む | 関係ない情報が多いと注意が分散 | 必要な情報に絞って渡す |
| 確率的に出力する | 同じ指示でも結果がブレる | テストで検証、重要な処理は複数回確認 |
| 学習データの「よくあるパターン」に引っ張られる | 独自ルールより一般的な書き方を優先 | 「既存の〇〇と同じ書き方で」と具体例を示す |

> **AIは考えているというより、膨大な経験から最も自然な続きを組み立てている。**
> そう理解しておくと、どこを信頼し、どこを検証すべきか判断しやすい。
