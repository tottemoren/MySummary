## 1. エディタ：VS Code

**ショートカット（Mac）**
| 操作 | キー |
|---|---|
| ファイルを名前で開く | `Cmd + P` |
| コマンドパレット | `Cmd + Shift + P` |
| プロジェクト全体を検索 | `Cmd + Shift + F` |
| 定義に移動 | `F12` / `Cmd + クリック` |
| 使用箇所を探す | `Shift + F12` |
| 名前の一括変更 | `F2` |
| 同じ単語を複数選択 | `Cmd + D` |

**拡張機能**：ESLint / Prettier、GitLens、Error Lens、使う言語の公式拡張

**保存時に自動整形する設定**
```json
{
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": { "source.fixAll.eslint": "explicit" }
}
```

## 3. ターミナルと CLI ツール

### 基本コマンド
| コマンド | 意味 |
|---|---|
| `pwd` | 今いる場所 |
| `ls -la` | ファイル一覧（隠しファイルも） |
| `cd フォルダ名` | 移動（`cd ..` で1つ上） |
| `mkdir フォルダ名` | フォルダを作る |
| `cat ファイル名` | 中身を表示 |
| `grep "文字列" -r .` | 文字列を探す |

### 便利な CLI ツール（Homebrew で入れる）
```bash
brew install ripgrep fzf bat eza jq gh
```
| ツール | 何をするか | 例 |
|---|---|---|
| **ripgrep（rg）** | 超高速な検索 | `rg "useState" src/` |
| **fzf** | あいまい検索 | `Ctrl + R` で履歴をあいまい検索 |
| **bat** | 色付き表示 | `bat package.json` |
| **eza** | 見やすいファイル一覧 | `eza -la --tree --level=2` |
| **jq** | JSON の整形・抽出 | `curl -s https://api.github.com/users/octocat \| jq '.name'` |

## 4. Git と GitHub

### 基本の流れ
```bash
git switch -c feature/login-form      # ブランチを作って切り替え
git status                            # 何が変わったか
git diff                              # 変更内容を詳しく
git add src/components/LoginForm.tsx  # コミット対象を選ぶ
git commit -m "ログインフォームにパスワード表示切り替えを追加"
git push -u origin feature/login-form # GitHub に送る
```

### 困ったとき
| 状況 | コマンド |
|---|---|
| 履歴を見やすく | `git log --oneline --graph` |
| この行を誰がいつ変えたか | `git blame ファイル名` |
| 作業を一時退避 | `git stash` → `git stash pop` |
| 直前のコミットメッセージを直す | `git commit --amend` |
| 消した変更を探す | `git reflog` |

### GitHub CLI（gh）
```bash
gh pr create --title "ログインフォーム改善" --body "パスワード表示切り替えを追加"
gh pr list
gh pr checkout 42
```
**lazygit**：Git を画面で操作できる。慣れないうちに便利。

## 5. 実行環境

### バージョン管理ツール：mise
```bash
mise use node@22
mise use python@3.12
```
フォルダに入ると自動でバージョンが切り替わる。言語別には nvm / fnm（Node.js）、uv / pyenv（Python）も定番。

### パッケージマネージャー
| 言語 | ツール | 例 |
|---|---|---|
| JavaScript | npm / **pnpm** / yarn | `pnpm add zod` |
| Python | **uv** / pip | `uv add fastapi` |

### Docker：誰の PC でも同じ環境で動かす
```yaml
# docker-compose.yml
services:
  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: devpassword
    ports:
      - "5432:5432"
```
```bash
docker compose up -d   # 起動
docker compose down    # 停止
```
Mac では **OrbStack** が軽量で人気。

## 6. デバッグ・確認ツール

### ブラウザの開発者ツール（`Cmd + Option + I`）
| タブ | 使い道 |
|---|---|
| **Elements** | HTML/CSS を確認し、その場で書き換えて試す |
| **Console** | エラー確認、JavaScript の実行 |
| **Network** | API 通信の中身・ステータス・時間 |
| **Application** | Cookie や localStorage |
| **Lighthouse** | 表示速度・アクセシビリティの採点 |

例：「保存されない」→ Network タブ → 400 なら送信データ、500 ならサーバー側を疑う。

### API クライアント
Postman、Bruno、Insomnia、VS Code 拡張の REST Client。
```http
### ユーザー作成
POST http://localhost:3000/api/users
Content-Type: application/json

{ "name": "テスト太郎", "email": "test@example.com" }
```
```bash
curl -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d '{"name":"テスト太郎"}'
```

### DB クライアント
TablePlus、DBeaver（無料）、Prisma Studio（`npx prisma studio`）

## 7. コード品質ツール（AI開発で特に重要）

| 種類 | 役割 | JS/TS | Python |
|---|---|---|---|
| **Formatter** | 見た目を揃える | Prettier、Biome | Ruff |
| **Linter** | 問題のある書き方を指摘 | ESLint、Biome | Ruff |
| **型チェック** | 型の間違いを検出 | TypeScript（`tsc`） | mypy、pyright |
| **ユニットテスト** | 関数単位の確認 | Vitest、Jest | pytest |
| **E2E テスト** | ブラウザ操作での確認 | Playwright | Playwright |

```json
{
  "scripts": {
    "check": "prettier --check . && eslint . && tsc --noEmit && vitest run"
  }
}
```

### CI（GitHub Actions）
```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npm run check
```

## まとめ

- **最初は必須のものに絞る**：VS Code、Git と GitHub、ターミナル、ブラウザの開発者ツール、Claude Code
- **AI開発で特に大事なのは品質ツール**：Formatter、Linter、型チェック、テスト、CI で、AIの間違いを機械的に止める
- **道具は使いながら増やす**：「この作業、毎回面倒だな」と感じたときが追加のタイミング
